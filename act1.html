10 Insights or new learnings that I gained in the Video Lesson.

1. A collection of all parts of the internet makes up the entire internet while the World Wide Web(applications using hyper-text transfer protocol) is considered only one of these parts.

2. Internet service providers provide users with internet connectivity and link users with the Internet as a whole.

3. Each computer on the internet has its own unique identification number called an IP address. The Domain Name System (DNS) translates each of these into user friendly names so we use as website URLs.

4. The web has a system of URLs that identify the exact location of a file or page. URLs work much like a physical address. They uniquely identify a resource (file/page) by its location on the internet.

5. Different types of websites exist based upon what the website is intended to accomplish (examples: business, blog, e‑commerce, news/documentation).

6. The purpose of a sitemap is to provide a means for visitors to navigate easily through your website without getting lost.

7. HTML and CSS work in together to determine which content should display on a page and what that content will look like when displayed on the webpage.

8. Web structure exists in three different formats or structure: (1) linear layout (2) hierarchical format (3) web-based format.

9. Creating websites that are quick, safe, and easy to use will be made easier by following to the standards and criteria established by web standards organizations.

10. Content editors have access to many different types of tools to assist them with their editing work, included basic text editors, Content Management Systems (CMS) for managing website content, etc.
